# Starfall Tactics: War of the Riven Crown

A Final Fantasy Tactics-style isometric tactics RPG set in the Starfall mythology —
573 collectible creatures, 17 job disciplines, hero campaign, wardrobe skins, and
animated ultimate arts.

**Play:** open `index.html`, or the GitHub Pages deployment of this repository.

This repository contains the built game (all assets included). Save data lives in
your browser; use the in-game Back up / Load a file buttons to move saves between devices.
